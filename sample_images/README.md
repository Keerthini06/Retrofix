# Sample images for manual testing

No external dataset is required. Use personal photographs with permission, or download these old-photo examples from Wikimedia Commons. Open each file page, review the license shown there, and click **Original file** to download.

- [Old photo 1880 — public domain](https://commons.wikimedia.org/wiki/File:Old_photo_1880.jpg)
- [Framed portrait from the Rijksmuseum — CC0 1.0](https://commons.wikimedia.org/wiki/File:Ingelijste_portretfoto_van_een_oudere_vrouw,_RP-F-00-6917-10.jpg)
- [Robert Cornelius portrait — public domain](https://commons.wikimedia.org/wiki/File:RobertCornelius.jpg)

The source photos are not guaranteed to contain scratches or creases. For a controlled brush demonstration, save a separate copy and add a few thin white/dark lines in a basic image editor. Preserve the clean original so you can compare the restoration result.
